What the builder guarantees
  • Teaching type sets the lane shape — you can't enter an invalid combination.
  • Pipe / comma counts are derived, never hand-typed → the #1 hard error disappears.
  • Teacher & room fields are dropdowns sourced live from the foundation sheets.
  • Blank class auto-fills "all sections of this grade" (matches spec defaulting).
  • The CSV preview teaches the underlying format for anyone who later wants the grid.
✎ This single component absorbs ~80% of the spec's branching. Build it first; everything else is flat tables.
