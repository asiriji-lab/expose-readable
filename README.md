# ScheDool
An AI-powered automated scheduling software for schools. 

## Setup
1. Clone the repository. `git clone https://github.com/ScheDool/schedool`
2. Copy the `.env.local` to `.env` and fill in the fields.
3. Do `docker compose up -d`
4. Go to `http://localhost:3000`
5. Have fun!
